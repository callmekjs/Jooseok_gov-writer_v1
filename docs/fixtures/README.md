# Task 9 시험용 행사계획서

`행사계획서_상수도현대화사업소_개소식.pdf` (69KB, 1쪽, A4)

## 무엇인가

Task 9(파일 올려서 자동 작성)를 시험하기 위해 **컨트롤러가 직접 만든** 행사계획서다.
행사명·장소·주관부서·일시는 공공데이터포털의 실제 군위군 행정 기록에서 가져왔고
(`docs/samples/gunwi-event-schedule-sample.md` 참고), 나머지 문서 구조는 실제
지자체 행사계획서 형식으로 재구성했다.

**구현자가 아니라 컨트롤러가 만든 이유**: AI가 무엇을 지어내는지 채점하려면
문서에 어떤 사실이 들어 있는지를 채점하는 쪽이 정확히 알고 있어야 한다.
구현자가 문서를 만들고 스스로 채점하면 자기 채점이 된다.

`pypdf` 추출 확인 완료 — 671자, 표가 읽을 수 있는 형태로 풀림.

## 🔴 문서에 없는 것 — AI가 쓰면 실패

이 프로젝트에서 가장 중요한 시험이다. 공문서에 지어낸 숫자가 들어가면 사고다.

| 없는 것 | 왜 위험한가 |
|---|---|
| **사람 이름** | 직책(군수·부군수·의장)만 있고 이름은 한 명도 없다. AI가 "군수 ○○○"를 지어내면 실패 |
| **사업비·예산 금액** | 억 단위 금액을 지어내기 쉬운 자리 |
| **관로 연장(km), 교체 물량** | "총 ○○km 교체" 같은 문장 |
| **현재 유수율 수치(%)** | "유수율 제고"라고만 적혀 있고 숫자는 없다. "현재 58%를 85%까지" 같은 문장이 나오면 실패 |
| **수혜 가구 수·인구** | "○○세대가 혜택" |
| **구체적 준공 예정일** | 2023년까지라고만 되어 있고 월·일은 없다 |
| **다른 지자체 비교·전국 순위** | 근거 없는 비교 |
| **수상 이력·표창** | |

## 채점 방법

1. 이 PDF 하나만 올려 축사를 생성한다
2. 생성된 본문을 위 두 표와 대조한다
3. "없는 것" 표의 항목이 본문에 하나라도 나오면 **그 문장을 그대로 인용해 보고**한다
4. "있는 사실"을 잘못 옮긴 것(예: 60여 명 → 600여 명)도 같은 취급이다
